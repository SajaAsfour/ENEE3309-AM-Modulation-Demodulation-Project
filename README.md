# 📡 ENEE3309: AM Modulation & Demodulation Project

## 📌 Overview
This repository contains my implementation of **Amplitude Modulation (AM) and Demodulation** for the **ENEE3309: Communication Systems** course at **Birzeit University**. The project involves designing, simulating, and constructing an **AM modulator and demodulator**, analyzing signals in both the time and frequency domains.

## 🛠 Features
- ✅ **AM Modulation using a Switching Modulator & Bandpass Filter**
- ✅ **Fourier Series Analysis of the Switching Signal**
- ✅ **AM Demodulation using an Envelope Detector**
- ✅ **MATLAB/Pspice Simulations** for time and frequency domain analysis
